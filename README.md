## Overview

The portfolio brings together projects, experience, education, certifications, and contact details in one page.

The design uses custom typography, CSS visuals, 3D elements, and motion effects.

## Features

* Responsive single-page layout
* Custom typography and visual system
* Three.js background
* GSAP scroll animations
* Lenis smooth scrolling
* Anime.js animations
* Magnetic button interactions
* Pointer based card movement
* Scroll-linked motion
* Reduced-motion support
